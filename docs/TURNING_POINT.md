# 转折点：从「选择自然算法」到「证据纪律下生成算法」

日期：2026-08-24。本文是项目第三次方向转折的章程，批判性核验、
序列计划与非目标都在这里。前两次转折见 AUDIT_NOTE（VBS 差距 ~3% 否定
「更好的平均算法」；Fields2Benchmark 存在否定「再建基准平台」）。

## 一、转折定义

**AgriAutoLab = 农业 CPP 的研究仪器 + 分析/选择层**（定位不变），
其上发起生成式研究线：

> **把 LLM 驱动的自动启发式设计（AHD/AHSD，EoH/EoH-S 范式）引入农业 CPP：
> 在冻结的三目标 Pareto 基准上进化覆盖规划启发式（行向选择 / 条带排序 /
> 地头转弯选择），适应度 = 前沿超体积增量，全部运行走既有证据链。**
> 不可主张「首次进化互补启发式集合」（EoH-S 已做）；可主张的是领域引入
> + 农业语义三目标 ΔHV 评价信号 + 冻结真实地块基准与证据链验证。

学术主张随之从「选得更好」升级为可检验的生成式问题：
自然算法池互补不足时，自动算法设计能否真实增加 Pareto 超体积？
——这正是 L4 选择层反衬出来的下一问。

## 三、序列计划（顺序不可换；D0.4 为执行规范封口，已随修正案 05 完成）

0. **D0.4 封口（已完成）**：修正案 05——偏好网格坐标级冻结
   （PREFERENCE_GRID_V1，22 点，哈希进协议）、零权重契约、H2 常数响应
   记 0、H3 田级聚合与非 oracle 基线、不可行罚则、检验统计量总表。
   **此后 confirmatory protocol 冻结，只允许新 study 注册。**
1. **D1–D2**：CV 折落盘（seed 20260822）+ 拒绝/有效池普查。
2. **D3–D4**：选择评估协议（三层基线）+ 推荐器（sklearn 式
   fit/recommend）。**H1/H2 只依赖冻结语料，D1/D2 后即可与推荐器
   开发并行执行。**
3. **D5–D7**：H1 → H2 → H3（**留出集只在此一次性打开**，双轨 70/68）。
   这一步同时产出「自然池互补有限」的量化证据——生成式研究线的动机。
4. **D8**：探索性 ISA / 解释 / 消融（明确标注 exploratory）。
5. **Study-002 预注册（生成式）**：个体 = 启发式代码（三槽位）；
   适应度 = 训练折上 ΔHV（对当前前沿）；留出集只在最终评估用一次；
   对照 = 自然池 13 配置、随机启发式、**EoH-S（AAAI 2026，互补启发式
   集合进化——本研究线最近的方法学邻居，必须作直接基线而非仅
   related work）**；LLM 后端版本/温度/种子/成本全部进证据链；四道
   安全闸与对抗式复核既有实现直接复用。
6. **可选扩展（Study-003+ 候选，不捆绑）**：能耗第四目标（USV 功率-
   边权方法移植）、课程 RL、扩散轨迹生成、多机 MAPF。

## 四、非目标（明确不做）

- 不再大规模改包名/搬目录（canonical+wire 双层已定）；
- 不在 Block D 结论出来之前动 LLM 线的任何实跑；
- 不把能耗/多机等扩展捆进本轮；
- 留出集与预注册纪律不因新方向松动（探针田披露与双轨并报沿用）。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| LLM 非确定性破坏可复现性 | 请求-响应全量落盘进 evidence；模型版本钉死；重放验证 |
| 进化出的启发式过拟合训练折 | 适应度只看训练折，留出集一次性评估（与 H3 同构的纪律） |
| 「空白」判断过期 | 定稿前重跑聚焦文献核查 |
| 生成线抢走选择线的统计严谨性 | 序列计划锁定：Block D 先行，Study-002 后注册后跑 |
