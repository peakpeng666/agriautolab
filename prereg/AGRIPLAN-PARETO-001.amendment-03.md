# AGRIPLAN-PARETO-001 预注册修正案 03：双机具语料的统计单位、估计量与留出集披露

日期：2026-08-22。承接修正案 02（统计单位 3500 实例 → 350 地块 → 235 自由许可地块）。
原封存 yaml（sha256 `8d1326de…`）不回改、不重封。

## 1. 为什么需要本修正案

修正案 02 早于双机具设计一天。终语料 v7（提交 ed1bccb）的实例结构是
地块 × 5 行角 × 2 行距 × 2 机具 = 4 700 行实例。同地块的 20 个实例共享
几何，前沿大小与特征强相关——**若把 4 700 实例当独立单位做 H1/H2 检验，
显著性被伪重复虚增近 √20 倍**。本修正案在任何地块层分析之前钉死口径。

## 2. 统计单位与估计量（H1/H2/H3 通用）

- **独立单位恒为地块，n = 235**（修正案 02 不变；许可裁定前不扩）。
- **分析池 = corpus_13**（pool_hash `aa0e4aaada76bf19cb24459e6b1cc53ec7aa199ac9d27cf50a634f98fc99e184`，
  含 RS 两槽位；RS-A 仅在可倒车机具上贡献，构成设计的一部分而非排除项）。
- **H1 估计量**：地块内「有前沿的实例」（≥1 ok 配置）前沿大小的中位数，
  得 235 个地块值；主检验 = 对 1.0 的单侧 Wilcoxon 符号秩（alpha 0.01，
  Holm-Bonferroni 族不变）。地块内无前沿的地块不进主检验，但**零 ok
  地块份额（实况 42/235）作为共同报告量**，敏感性口径（零 ok 实例计
  前沿 = 0 后再取地块中位）并报。失效判据沿用原文并加一条：零 ok
  地块份额 > 30% 时 H1 的「策略非嵌套支配」解释效力单列讨论。
- **H2 估计量**：地块层配对——特征与前沿大小都先在地块内取中位
  （row_angle_vs_principal 按实例取值，随行角变化），Spearman 235 对。
- **H3**：留出集 = 已封存 70 块（seal_hash `be973254…`，field 级 30%，
  seed 20260821）。推荐器在训练侧 165 块上做分组 CV（10 折按 field_id
  分组、**seed = 20260822 写死于此**、指派表落盘进哈希链，**构造先于
  任何训练**），留出集只评估一次。

## 3. 已见统计量披露（防 QRP）

基建验证期已不可避免的描述统计：实例层前沿中位 v4 2.0 → v7 3.0
（manifest 自带）；有效池中位（manifest 口径）10.0、全实例口径 8.0、
均值 6.63。**地块层 H1 估计量（235 个地块中位数的分布与检验）截至本
修正案封存时点未计算**——此前一切数字均为实例层描述统计，不构成
对 H1 的偷看。

## 5. 与失效判据的衔接

原 H1 失效判据「中位数 == 1 或 > 90% 实例的前沿大小为 1」中的
「实例」按本修正案读作「**地块层估计量**」：地块中位数 == 1，
或 > 90% 地块的地块中位 == 1。H2/H3 失效判据不变，仅单位换地块。
